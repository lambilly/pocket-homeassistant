## 关键约束（改外壳必读）
- 前壳内腔必须净空（屏幕套柱安装），只允许动裙边和角柱。
- 加高实现方式：取干净截面环 → shapely 双段拉伸
  （直段内壁 28.05 + buffer 0.15 斜角段 28.2，与对件斜角对称成 V 阴线），
  **整段重建，不打补丁**（共面 union 补块会留发丝缝 → 缺口/裂缝）。
- 圆角矩形（如 Type-C 口）构造必须"竖条 + 横条 + 四角圆"，
  四角圆心 = (半宽−r, 半高−r)，**不要**用中线±偏移（会得到骨头形/耳朵）；
  开孔后用壁中线逐 z 扫宽度验证单段。
- `to_planar` 变换方向易反，改用 `section().discrete` 原始 3D 点建 Polygon。
- 前壳装配位需 180° 绕 X 翻转（不能直接平移，会得到假干涉）。
- cylinder(height=h) 以中心定位，translate 后实际跨 zc±h/2，按端点算会错位。

## 技术栈
- Python + trimesh（manifold3d 布尔）、shapely、numpy、matplotlib。
- 渲染中文需 `plt.rcParams["font.sans-serif"]=["Microsoft YaHei"]`。
- Windows 下 Python 读不了 git-bash 的 `/tmp` 字面路径，脚本内用项目内相对路径。
- 每次改版校验项：watertight、单一实体、外形尺寸、装配干涉（应 0）、
  接缝间隙（应 0）、螺丝 ⌀2.0 杆全通道射线、Type-C/固定孔三射线。
