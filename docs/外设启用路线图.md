## 待办：需要外加硬件或写组件

### 🟡 I2C 扩展口（IO38/39）
已开总线，插上就能用。**注意地址不能和触摸 0x55、ES8311 0x18 冲突**。推荐：
- `bme280` / `bmp280`（温度·湿度·气压）
- `sht3xd`（温湿度，精度更好）
- `bh1750`（光照，做自动亮度很合适）
- `ld2410`（毫米波人体存在，走 UART 更常见，也可 I2C 版）

注意：这个座子是 1.25mm 4P，需要配套端子线；总线已上拉（R17/R18 10K）。

### 🟡 UART 扩展口（IO43/44，1.25mm 4P）
日志走 USB，UART 空闲，可直接接串口设备：
- `pmsx003`（PMS5003 空气质量 PM1/2.5/10）
- `pzem004t`（电量计量，做全屋用电）
- `ld2410`（毫米波雷达，UART 版最常用）
配置：`uart: tx_pin: GPIO43, rx_pin: GPIO44, baud_rate: 9600`

### 🔴 触摸（ST77922 内置，I2C 0x55）
- 协议：16 位寄存器地址、单点 7 字节、必须一次性读完清缓冲、轮询约 30fps
- ESPHome 没有现成组件，`ft63x6`/`gt911` 都不适用
- 需要：写 `external_components` 自定义 touchscreen 组件（C++）
- **前置**：拿到商家资料包里的触摸例程（百度盘 an79），确认寄存器地址与位定义

### 🔴 音频输出（ES8311 → SC8002B → 喇叭）
- ES8311 是带 I2C 配置的 codec（0x18），不做初始化就没有声音
- 需要：自定义组件初始化 ES8311（时钟源、采样率 24kHz、DAC 上电、音量），再用 `i2s_audio` 的 `media_player` 推流
- PA 使能：IO1 **低电平使能**
- 用途：HA TTS 播报、门铃、提示音（原项目的音效可复用）

### 🔴 麦克风（ES8311 ADC）
- 模拟麦克风 → ES8311 ADC → I2S DI(IO16) → ESP32
- 需要：ES8311 初始化（ADC 通路）+ `microphone: platform: i2s_audio`
- 用途：HA 语音助手（STT 在 HA 侧）、噪音监测、对讲
- 进阶：microWakeWord 本地唤醒词（S3 + PSRAM 可跑）

### 🔴 TF 卡（SDIO 四位：CLK=5, CMD=4, D0~D3=6/7/2/3）
- ESPHome **官方没有 SD 卡组件**
- 需要：自定义组件挂载 SDMMC（1-bit 或 4-bit），或退化成 SPI 模式
- 用途：外置字库（省 Flash）、图片资源、音频 wav、离线日志
- 判断：优先级最低——16MB Flash 装现有 UI 足够
