## 待办：需要外加硬件或写组件

### 🟡 I2C 扩展口（IO38/39）
已开总线，插上就能用。**注意地址不能和触摸 0x55、ES8311 0x18 冲突**。推荐：
- `bme280` / `bmp280`（温度·湿度·气压）
- `sht3xd`（温湿度，精度更好）
- `bh1750`（光照，做自动亮度很合适）
- `ld2410`（毫米波人体存在，走 UART 更常见，也可 I2C 版）

注意：这个座子是 1.25mm 4P，需要配套端子线；总线已上拉（R17/R18 10K）。

### 🟡 UART 扩展口（IO43/44，1.25mm 4P）
日志走 USB，UART 空闲，可直接接串口设备：
- `pmsx003`（PMS5003 空气质量 PM1/2.5/10）
- `pzem004t`（电量计量，做全屋用电）
- `ld2410`（毫米波雷达，UART 版最常用）
配置：`uart: tx_pin: GPIO43, rx_pin: GPIO44, baud_rate: 9600`

### ✅ 触摸（ST77922 内置，I2C 0x55）— 已完成（2026-11-07）
- 协议：16 位寄存器地址（`0x0010` 状态 / `0x0014` 数据）、单点 7 字节、按 `0x0009` 最大触点数一次性读完排空 FIFO、轮询 50ms
- 实现：`components/st77922_touch/`（external_components local），上报原生竖屏坐标，旋转交给 LVGL
- 详见 `docs/触摸-ST77922.md`

### ✅ 音频输出（ES8311 → FM8002E → 喇叭）— 已完成（2026-11-07）
- ESPHome 2026.10 自带 `audio_dac: platform: es8311`，**不需要写 C++ 组件**
- 配置：`i2s_audio`(MCLK17/BCLK18/LRCK21) + `audio_dac: es8311`(I2C 0x18) + `speaker: platform: i2s_audio`(DOUT 15) + `speaker: platform: mixer` + `media_player: platform: speaker`
- PA 使能：IO1 **低电平使能**（`inverted: true`，播放前开、结束后延迟 150ms 关）
- 用途：HA TTS 播报、门铃、提示音
- 详见 `docs/音频-ES8311方案.md`

### ✅ 麦克风（ES8311 ADC）— 已启用（2026-11-08）
- 配置：`es8311` 的 `use_microphone: true` + `mic_gain: 24DB`，`microphone: platform: i2s_audio`（DIN 16, adc_type: external, 16k/16bit/left）
- 验证：`sensor: platform: sound_level`（`sensor.pocket_mic_rms`），安静 -70~-50dB，说话跳 10dB 以上
- 语音助手：`voice_assistant` + `media_player: pocket_media`，STT/意图/TTS 全在 HA 侧，暂用 HA 触发（无唤醒词）
- 进阶（未做）：microWakeWord 本地唤醒词（S3 + PSRAM 可跑，但和 LVGL 抢 CPU，需实测）

### 🔴 TF 卡（SDIO 四位：CLK=5, CMD=4, D0~D3=6/7/2/3）
- ESPHome **官方没有 SD 卡组件**
- 需要：自定义组件挂载 SDMMC（1-bit 或 4-bit），或退化成 SPI 模式
- 用途：外置字库（省 Flash）、图片资源、音频 wav、离线日志
- 判断：优先级最低——16MB Flash 装现有 UI 足够
