# 触摸驱动：ST77922 内置 TDDI（ES3C35P）

> 采集于 2026-11-07。实现见 `components/st77922_touch/`，配置见 `pocket-homeassistant.yaml` 的 `touchscreen:` 段。

## 为什么必须自己写

ESPHome 没有任何组件能直接驱动这颗触摸：

| 现成组件 | 为什么不能用 |
| -- | -- |
| `ft63x6`（FT6336U） | 寄存器地址 8 位、状态在 0x02、点在 0x03；ST77922 是 **16 位地址**、状态 0x0010、点 0x0014 |
| `gt911` | 协议完全不同（0x814E 状态、0x8150 点数据） |
| `xpt2046` | 电阻屏 SPI，不是电容 I2C |

所以按 ESPHome 的 `touchscreen` 基类写了一个外部组件。

## 协议（已核实，来源：厂家例程 / xiaozhi-esp32 的 lcdwiki-es3c35p 移植）

- I2C 从机地址 **0x55**
- 寄存器地址 **16 位、大端**（先发高字节）
- 必须用 `write_read` 方式（写 2 字节地址，立刻读数据），不能分两次事务

| 寄存器 | 长度 | 含义 |
| -- | -- | -- |
| `0x0010` | 1 B | 状态。**bit3 (0x08) = 有触摸** |
| `0x0009` | 1 B | 最大触点数（这块屏实际按 1 点用） |
| `0x0014` | 7 B/点 | 首点数据 |

单点 7 字节布局：

| 字节 | 位 | 含义 |
| -- | -- | -- |
| 0 | bit7 | 该点有效（0x80） |
| 0 | bit0~5 | X 高 6 位 |
| 1 | 8 位 | X 低 8 位 |
| 2 | bit0~5 | Y 高 6 位 |
| 3 | 8 位 | Y 低 8 位 |
| 4 | — | 压力 / 重量 |
| 5~6 | — | 保留 |

```
x = ((buf[0] & 0x3F) << 8) | buf[1]
y = ((buf[2] & 0x3F) << 8) | buf[3]
```

⚠️ **必须一次性读完 7 字节**，分次读控制器不清缓冲，下一点读不出来。
⚠️ 厂家也是**轮询**（约 30fps），没有可靠的中断上报方式；INT(IO47) 只作输入保留。

## 引脚

| 信号 | GPIO | 说明 |
| -- | -- | -- |
| SDA | IO38 | 与 ES8311(0x18)、扩展 I2C 座共用 |
| SCL | IO39 | 同上 |
| RST | IO48 | 低电平复位，驱动上电拉低 20ms 再放高，等 100ms |
| INT | IO47 | 低有效，本驱动不用 |

## 坐标系与屏幕旋转

屏幕原生 **320×480 竖屏**，`rotation: 90°` 后画布是 **480×320**（横装）。
触摸原始坐标始终是面板原生的 320×480，所以必须做轴交换：

```yaml
touchscreen:
  - platform: st77922_touch
    display: lcd
    transform:
      swap_xy: true     # 先交换 XY，宽度才对得上
      mirror_x: false   # 方向反了再开
      mirror_y: false
```

### 方向不对怎么调（点左上角，看屏幕上的 `map` 读数）

屏幕会画出触点圆点和 `raw` / `map` 两行坐标。以点**左上角**为基准：

| map 读数 | 说明 | 改法 |
| -- | -- | -- |
| ≈ (0, 0) | 正确 | 不用改 |
| ≈ (479, 0) | 左右反了 | `mirror_y: true` |
| ≈ (0, 319) | 上下反了 | `mirror_x: true` |
| ≈ (479, 319) | 转反了（180°） | `mirror_x: true` + `mirror_y: true` |

> 注意：`transform` 是在 display 的 rotation 之后应用的，所以镜像轴和直觉的 X/Y 是交叉的——
> 上表的 `mirror_y` 管左右、`mirror_x` 管上下，是因为 swap_xy 已经先交换过一次。

## 已知限制

1. 只做单点（这块屏实际用不到多点手势）
2. 轮询 50ms（20fps），够点击和简单滑动；要做丝滑滚动可以降到 30ms
3. 与 ES8311 共享 I2C，等音频启用后要注意总线争用（400kHz 下读 7 字节约 0.2ms，影响很小）
4. 上电瞬间偶尔读到 (0,0)，驱动里已过滤，避免误判成左上角点击
