# 音频方案（ES8311 + FM8002E + MEMS 麦）

> 状态：2026-11-07 调研完成，**ESPHome 官方组件已覆盖，不需要写 C++ 组件**。
> 本文只描述方案与配置草案；正式启用前需要一轮独立调试（听声/调增益/测 CPU）。

## 1. 硬件链路

```
ESP32-S3 ──I2S(BCLK18/LRCK21/MCLK17)──> ES8311 codec ──模拟──> FM8002E 功放 ──> 喇叭
         └──I2S_DOUT(IO15)──────────────┘                            ↑
         ┌──I2S_DIN(IO16)───────────────┘                            │
         │                                                    PA_EN(IO1) 低电平使能
         └──I2C(IO38/39, addr 0x18)──> ES8311 控制寄存器             
MEMS 麦 ──模拟──> ES8311 ADC ──I2S_DIN──> ESP32-S3
```

| 信号 | GPIO | 说明 |
| -- | -- | -- |
| MCLK | IO17 | ES8311 主时钟（16kHz × 256 = 4.096MHz） |
| BCLK | IO18 | I2S 位时钟 |
| DOUT | IO15 | 数据 → codec DAC（接 ES8311 的 SDIN） |
| DIN | IO16 | 数据 ← codec ADC（麦克风） |
| LRCK | IO21 | 左右声道时钟 = 采样率 |
| PA_EN | IO1 | 功放使能，**低电平开**（低有效，与直觉相反） |
| I2C | IO38/39 | 与触摸共用总线，地址 0x18（触摸 0x55，不冲突） |

## 2. ESPHome 现成组件（本地 2026.10.1 已包含）

| 组件 | 作用 |
| -- | -- |
| `audio_dac: platform: es8311` | I2C 初始化 codec：时钟源、采样率、DAC/ADC 上电、音量、静音；`use_microphone: true` 同时开 ADC 通路 |
| `i2s_audio` | I2S 总线（TX/RX 可共用同一 bus id） |
| `speaker: platform: i2s_audio` | 音频输出，通过 `audio_dac:` 绑定 ES8311（音量/静音走 I2C） |
| `microphone: platform: i2s_audio` | 麦克风采集，`adc_type: external` + `i2s_din_pin: GPIO16` |
| `media_player: platform: speaker` | 变成 HA 里的 media_player 实体 → 接 TTS / 播放 URL |
| `voice_assistant` | 语音助手（STT 在 HA 侧，可配 microWakeWord 本地唤醒） |

## 3. 能做哪些事（按落地难度排序）

| 优先级 | 功能 | 说明 | 依赖 |
| -- | -- | -- | -- |
| P1 | **TTS 语音播报** | HA 自动化调 `media_player.play_media` → 门铃、洗衣机完成、天气、通知朗读 | speaker + media_player + HA TTS |
| P1 | **提示音/告警音** | 本地 wav 播放（原项目 `sounds/` 可复用），如低电量、离线、按键音 | speaker |
| P2 | **麦克风电平/噪音监测** | RMS → sensor，可做"环境噪音"显示、拍手检测 | microphone |
| P2 | **语音助手（Assist）** | 按住/唤醒说话 → HA 理解 → 控制设备；S3+PSRAM 可跑 microWakeWord 本地唤醒词 | voice_assistant |
| P3 | **对讲/留言** | HA 侧录音 → 屏幕播放；或屏幕录音 → HA | microphone + speaker 全双工 |
| P3 | **TF 卡音频资源** | 16MB Flash 够放十几个提示音，不必上 TF 卡 | speaker |

**限制与注意**

1. **单 I2S 总线**：S3 支持全双工（TX/RX 同时），但 LVGL 全屏刷新（QSPI 40MHz）+ 音频 DMA 同时跑，CPU 会紧张；建议音频只在"播报时"开启，播完关 PA。
2. **PA_EN 时序**：ES8311 输出稳定后再拉低 IO1，否则有"啪"声；停止播放后延迟 ~100ms 再关。
3. **采样率**：ES8311 与 speaker 必须一致（建议 16kHz/16bit 单声道，TTS 默认就是 16k）。
4. **MCLK**：`use_mclk: true`，ES8311 由 ESP32 提供 MCLK；若无声先查 MCLK 是否真的输出。
5. **增益**：麦克风 `mic_gain` 默认 42dB，板载 MEMS 麦可能只需要 18~24dB，需实测。
6. **固件体积**：加音频约 +150~250KB，16MB Flash 无压力。

## 4. 配置（已落地于 `pocket-homeassistant.yaml`）

```yaml
i2s_audio:
  - id: i2s_bus
    i2s_lrclk_pin: GPIO21
    i2s_bclk_pin: GPIO18
    i2s_mclk_pin: GPIO17

audio_dac:
  - platform: es8311
    id: es8311_dac
    i2c_id: bus_a            # 与触摸共用的 I2C 总线 id
    sample_rate: 16000
    bits_per_sample: 16bit
    use_mclk: true
    use_microphone: true     # 同时打开 ADC（麦克风）通路
    mic_gain: 24DB

speaker:
  - platform: i2s_audio
    id: spk_out
    i2s_audio_id: i2s_bus
    dac_type: external
    audio_dac: es8311_dac
    i2s_dout_pin: GPIO15
    sample_rate: 16000
    bits_per_sample: 16bit
    channel: mono
    buffer_duration: 200ms
  # ESPHome 要求"公告/媒体"两条管线各用独立 speaker
  # → mixer 把一路物理喇叭拆成两个虚拟 source，混音后统一送 spk_out
  - platform: mixer
    id: spk_mix
    output_speaker: spk_out
    num_channels: 1
    source_speakers:
      - id: spk_announce
      - id: spk_media

media_player:
  - platform: speaker
    id: pocket_media
    name: "Pocket Speaker"
    announcement_pipeline:
      speaker: spk_announce
      format: WAV
      sample_rate: 16000
      num_channels: 1
    media_pipeline:
      speaker: spk_media
      format: NONE          # NONE = 打开 WAV/MP3/FLAC 全部解码器
      sample_rate: 16000
      num_channels: 1
    volume_initial: 0.6
    task_stack_in_psram: true
    on_play:
      - switch.turn_on: pa_en
    on_announcement:
      - switch.turn_on: pa_en
    on_idle:
      - delay: 150ms
      - switch.turn_off: pa_en

switch:
  - platform: gpio
    id: pa_en
    pin:
      number: GPIO1
      inverted: true        # ON = 输出低 = 功放使能
    restore_mode: ALWAYS_OFF
```

> 已落地版本见 `pocket-homeassistant.yaml` 的 "音频输出" 段（2026-11-07 第一轮）。

### HA 侧播报 TTS

```yaml
action: tts.speak
target:
  entity_id: tts.piper              # 换成你的 TTS 实体
data:
  media_player_entity_id: media_player.pocket_speaker
  message: "洗衣机洗好了，记得晾衣服"
  cache: true
```

或直接播 URL：

```yaml
action: media_player.play_media
target:
  entity_id: media_player.pocket_speaker
data:
  media_content_id: "http://你的HA地址/local/tts/ding.wav"
  media_content_type: music
```

## 5. 麦克风与语音助手（2026-11-08 落地）

### 设备侧配置（实际值）

```yaml
audio_dac:
  - platform: es8311
    id: es8311_dac
    i2c_id: touch_i2c
    sample_rate: 16000
    bits_per_sample: 16bit
    use_mclk: true
    use_microphone: true      # 打开 ADC 通路
    mic_gain: 24DB            # 八档枚举：0/6/12/18/24/30/36/42

microphone:
  - platform: i2s_audio
    id: mic_in
    i2s_audio_id: i2s_bus     # 与喇叭共用总线（S3 全双工，采样率必须一致）
    adc_type: external
    i2s_din_pin: GPIO16
    sample_rate: 16000
    bits_per_sample: 16bit
    channel: left

voice_assistant:
  id: va
  microphone:
    microphone: mic_in
    gain_factor: 4            # 软件增益 1~64（4 = +12dB）
    bits_per_sample: 16
    channels: 0
  media_player: pocket_media  # 与 speaker 互斥
  use_wake_word: false
  noise_suppression_level: 2
  auto_gain: 0dBFS
  volume_multiplier: 1.0
  conversation_timeout: 120s

sensor:
  - platform: sound_level
    microphone:
      microphone: mic_in
    passive: false
    measurement_duration: 1000ms
    rms:
      name: "Pocket Mic RMS"
```

### 验证顺序（别跳步）

1. **看电平**：HA 里 `sensor.pocket_mic_rms`，安静时约 -70 ~ -50 dB，说话/拍手应跳 10 dB 以上。贴死在 -90 或 -100 说明 ADC 没起来（查 `use_microphone` 与 I2C 写寄存器日志）。
2. **试听录音**：开发者工具 → 服务 → `esphome.pocket_homeassistant_start_voice_assistant` 之类不适用于本配置；直接做第 3 步。
3. **HA 侧建 pipeline**：设置 → 语音助手 → 添加助手
   - 语言选中文；STT 选 Whisper / faster-whisper / HA Cloud（需有中文模型）
   - TTS 选 Piper（`zh_CN-huayan-medium` 一类中文音色）或 HA Cloud
   - 保存后在设备卡片里把该 pipeline 指定给 `assist_satellite.*` 实体
4. **触发对话**：HA 里对 `assist_satellite.<设备>_assist_satellite` 调服务 `assist_satellite.start_conversation`，然后对着屏说话。

### 调参经验

| 现象 | 处理 |
| -- | -- |
| 电平很低但能听清 | `mic_gain` 升一档（24→30），或 `gain_factor` 4→8 |
| 声音发破 / STT 识别差 | `mic_gain` 降一档（24→18），`gain_factor` 回 1 |
| 播报时把自己说的又听进去 | 音量压到 60% 以下；或播报期间停止采集（ESPHome 无 AEC） |
| 播放有爆音/卡顿 | `speaker.buffer_duration` 200ms → 300ms；关闭 LVGL 动画 |
| Assist 无响应 | 看日志 `VA: error code=...`；常见是 HA 侧 pipeline 未指定或 STT 未加载 |

> 电平验证通过后，可把 `sound_level` 的 `passive` 改成 `true`（或整段注释）减少 CPU 占用；
> 语音助手本身不需要这个传感器。

## 6. 建议实施顺序

1. **第一轮（出声）** ✅ 2026-11-07：`i2s_audio` + `audio_dac` + `speaker`，HA 里出现 `media_player.pocket_speaker`。
2. **第二轮（播报）** ✅ 2026-11-07：接 HA TTS，`tts.speak` 指向该 media_player。
3. **第三轮（麦克风）** ✅ 2026-11-08：`use_microphone: true` + `microphone` + `sound_level`。
4. **第四轮（语音助手）** ✅ 2026-11-08：`voice_assistant`（无唤醒词，HA 触发）。
5. **第五轮（本地唤醒词）** ⬜ 待做：`micro_wake_word` + 模型（占用数 MB，与 LVGL 抢 CPU）。

## 7. 与旧项目（2.8 寸）的差异

- 旧板是 **MAX98357A**（纯 I2S 功放，无需 codec 初始化）→ 直接 `speaker: platform: i2s_audio`。
- 新板是 **ES8311 + FM8002E**，必须先用 I2C 初始化 codec，否则完全没声。这是本次最大的差异点。
